## PLAYX 内部構造（再構成）

PLAYXは、SHARP PC-E500シリーズ用の常駐型ブザー音楽ドライバであり、
単一の1bit内蔵スピーカーを用いて3声のポリフォニック再生を実現します。

本内容は、オリジナルバイナリの逆アセンブルおよび解析に基づいています。

---

### 概要

PLAYXは、BASIC拡張コマンドとして動作するドライバです。

| アドレス | 関数名            | 機能 |
|---------|-------------------|------|
| BF000   | PLAYX_ENTRY       | BASICコマンド登録エントリ |
| BF013   | PLAYX_CMD_TABLE   | 命令名テーブル ("PLAYX") |
| BF022   | PLAYX_INIT        | 初期化・パラメータ設定 |
| BF08D   | FIND_PARTS        | MML文字列の声部分割 |
| BF15F   | MML_DISPATCH      | MMLコマンド解析 |
| BF1F4   | PITCH_CALC        | 音程・音符長計算 |
| BF26C   | EXIT              | BASIC復帰 |
| BF272   | VOICE_ROUTE       | 自己書き換えルーティング |
| BF290   | SOUND_GEN         | 3声部音声生成ループ |
| BF2CA   | データ領域        | 音程テーブル・音符長テーブル |

---

### MMLコマンド

PLAYXは内部にMMLパーサを持ちます。

確認済みコマンド：

- 音階: `A B C D E F G`
- オクターブ: `O`
- テンポ: `T`
- シャープ/フラット: `+ -`
- オクターブ移動: `< >`

`MML_DISPATCH` で文字列を直接解析します。

---

### 三和音再生の仕組み

PLAYXは時分割処理により3声を実現します。

各声部を順番に処理し、

1. 音程値ロード
2. パルス出力
3. カウンタ更新
4. 次の声部へ

を高速に繰り返すことで、同時発音を擬似的に実現します。

---

### 自己書き換えコード

PLAYXの最大の特徴は自己書き換えコードです。

`VOICE_ROUTE` は `SOUND_GEN` 内の命令を書き換えます。

具体的には：

- SC62015の `D8` 命令でプログラム領域を書き換え
- 対象は `CC` 系命令の即値部分
- 音程カウンタ値（VREG）を動的に注入

これにより：

- 分岐を使わず高速処理
- 声部ごとの音程制御

が可能になります。

---

### データテーブル

BF2CA付近に配置：

- 音程テーブル
- 音符長テーブル（例：03,06,09,0C,12...）

`PITCH_CALC`で使用されます。

---

### 設計的特徴

PLAYXは以下の特徴を持ちます：

- BASIC統合型ドライバ
- 1bitブザーによるポリフォニー
- 時分割による多声処理
- 自己書き換えコードの活用
- テーブル駆動型設計

---

### 歴史的補足

PLAYXは後のPLAY3に影響を与えたと考えられます。

PLAY3はコードを引き継いでいないものの、

- MML制御
- ソフトウェアミキシング
- テーブル駆動

といった思想を継承しています。

また、PLAY3ではEXOFF命令などが追加され、
BASIC依存の強さが改善されています。
